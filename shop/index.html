常见问题

您可能想知道

关于夜狼小商城的一些常见问题解答

夜狼小商城适合哪些业务场景？
+

夜狼小商城适用于虚拟商品销售、代刷业务、卡密发卡、会员充值、游戏代练等多种场景。无论您是个人站长还是企业运营者，都可以通过夜狼小商城快速搭建属于自己的在线销售平台。

系统支持哪些支付方式？
+

系统支持支付宝（即时到账/当面付）、微信支付（Native/JSAPI/H5）、QQ 钱包、码支付、易支付、微付通等多种支付通道，可独立配置三网支付，灵活满足不同需求。

如何配置社区对接？支持哪些社区？
+

在后台「对接设置 - 对接站点管理」中添加社区账号即可。目前支持玖伍社区、卡易信、卡商网、卡乐购、聚梦、时空云以及同系统对接，商品价格会自动监控同步。

分站系统是如何运作的？

夜狼小商城支持三级分站架构。主站可开通一级分站，一级分站可开通二级分站。每个分站拥有独立管理后台、独立域名、独立商品与订单，分站之间通过加价模板实现差异化定价，提成自动结算。

系统的安全性如何保障？
+

夜狼小商城内置 360 Web 安全防护、网站安全扫描、顽固文件清理、操作日志记录、极验/顶象滑动验证码、黑名单机制等多重安全措施，全方位保障您的站点与资金安全。

是否提供技术支持和更新服务？
+

系统提供在线版本更新检查，可一键升级到最新版本。同时拥有完善的插件生态和社区支持，遇到问题可通过工单系统、社区论坛等多渠道获取帮助。
